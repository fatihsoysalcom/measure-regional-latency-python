# Measure Regional Latency Python

This Python script demonstrates the concept of regional latency by measuring the time it takes to fetch data from various geographical endpoints. It simulates how a user's experience can be impacted by the physical distance to the server hosting an application. The example highlights why deploying applications closer to their target audience is crucial for minimizing response times and improving user satisfaction.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Install the `requests` library: `pip install requests`
3. Run the script: `python main.py`
